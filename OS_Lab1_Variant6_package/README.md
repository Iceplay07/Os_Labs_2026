# Лабораторная работа №1 по ОС — вариант 6

## Вариант

Порядковый номер студента: `P = 6`.

В работе 22 варианта, поэтому:

```text
((P - 1) % N) + 1 = ((6 - 1) % 22) + 1 = 6
```

Следовательно, выполняется **вариант 6**.

Условие: в файле записаны команды вида `число число число<endline>`. Дочерний процесс считает сумму чисел каждой строки и выводит результат в стандартный поток вывода. Числа имеют тип `int`, количество чисел в строке произвольное. Родительский и дочерний процессы являются разными программами.

## Схема работы

```text
              имя файла
User --------------------------> parent
                                    |
                                    | open(file)
                                    | pipe()
                                    | fork()
                                    v
File ----> stdin ----> child ----> stdout ----> pipe1 ----> parent ----> stdout ----> User
                    execve()
```

После `fork()` дочерний процесс:

1. перенаправляет открытый файл на `STDIN_FILENO` через `dup2()`;
2. перенаправляет свой `STDOUT_FILENO` в пишущий конец `pipe1`;
3. закрывает лишние файловые дескрипторы;
4. вызывает `execve("./child", ...)`.

Родитель закрывает неиспользуемый пишущий конец pipe, читает результаты через `read()` и выводит их через `write()`.

## Ограничения

В исходниках не используются `iostream`, `fstream`, `stdio.h`, потоки C++ и высокоуровневый файловый ввод-вывод. Для работы с процессами, файлами и каналами используются POSIX-интерфейсы ОС: `open`, `close`, `pipe`, `fork`, `dup2`, `execve`, `read`, `write`, `waitpid`, `_exit`.

Из стандартной библиотеки C++ в `parent.cpp` используется только `std::string`, что соответствует объявленным ограничениям.

## Сборка

На Linux или macOS:

```bash
make
```

Либо вручную:

```bash
c++ -std=c++17 -Wall -Wextra -Wpedantic -O2 parent.cpp -o parent
c++ -std=c++17 -Wall -Wextra -Wpedantic -O2 child.cpp -o child
```

## Запуск

```bash
./parent
```

После запуска введите имя файла, например:

```text
input.txt
```

Для файла:

```text
1 2 3
10 -5 7 8
100
-1 -2 -3 -4
2147483647 -2147483648
```

программа выведет:

```text
6
20
100
-10
-1
```

## Файлы

- `parent.cpp` — родительский процесс;
- `child.cpp` — дочерняя программа;
- `Makefile` — сборка;
- `input.txt` — тестовый вход;
- `expected.txt` — ожидаемый результат.
